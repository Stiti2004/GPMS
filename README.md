# Gram Panchayat Management System (GPMS)

A full-stack web application developed using the **MERN stack** to manage and provide information related to the functioning of a Gram Panchayat.

## Overview

The Gram Panchayat Management System (GPMS) provides a centralized platform for managing Panchayat-related information and enables different categories of users to access the system based on their roles.

The system supports **administrators, Panchayat employees, citizens, and government officers**, with functionalities for data management, information retrieval, and reporting.

## Features

- Role-based access for different categories of users
- User registration and authentication
- Panchayat data management
- CRUD operations for authorized employees
- Information access for citizens
- Statistical reporting for government monitors
- Category-based dashboard and navigation

## Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Architecture:** MERN Stack

## User Roles

The system supports the following user categories:

- **System Administrator** – Manages the overall system
- **Panchayat Employees** – Enter, modify, and manage Panchayat data
- **Citizens** – Access information related to their village
- **Government Officers** – Access reports and statistical information
